# Event Nexus

An immersive, full-stack event management platform built with React, Node.js, and MySQL.

## Features
- Edge-to-edge responsive design.
- Admin, Organizer, and User roles.
- Event hosting and booking approval workflows.
- Mock payment integration.

## Setup
1. Clone the repository.
2. Run `npm install` in the root, `client`, and `server` folders.
3. Configure your MySQL database in `server/.env`.
4. Start with `npm run server` and `npm run client`.
